Manage all your WordPress sites from one AI chat. Create content, run your WooCommerce store, and handle admin tasks, wherever the sites are hosted.

== Description ==

AI Agent by SiteGround lets you manage one or multiple WordPress and WooCommerce sites from a single chat, powered by the latest AI models. Describe the task in plain language by chatting with the AI agent and it does the work on your site: it writes and publishes pages, fixes SEO gaps, updates plugins, manages products and orders, and handles users and settings. Connect several sites and it works across all of them at once, regardless of where each one is hosted.

Let’s say your bookstore's back-to-school sale starts Monday. Ask: "Create a landing page for my bookstore's back-to-school sale, with a hero section, featured categories and a signup form." The agent builds the page from native blocks and saves it as a draft for your review.

= What you can ask it to do =

The agent handles a [wide range of WordPress and WooCommerce tasks](https://siteground.com/kb/ai-agent-for-wordpress/?utm_source=wordpress&utm_medium=plugin-directory&utm_content=description):

* **Content and pages:** create, edit, publish, unpublish and delete posts and pages, with AI-written text and images. Build navigation menus, restructure categories and tags, moderate comments, manage the media library, and translate content into other languages.
* **SEO:** audit the site for missing SEO titles, meta descriptions, alt text and captions, then write them. On one B2B site, the agent wrote alt text for 80+ images and SEO titles for 14 core pages in about 35 minutes, against an estimated 7.5 hours by hand.
* **Plugins and themes:** install, update and remove them, or list everything installed with version numbers and update status.
* **WooCommerce:** create and update products, prices, descriptions and stock. View, update, cancel or delete orders. Pull sales reports, top products and coupon usage for any date range, and translate the full catalog with HTML formatting intact.
* **Settings and users:** change the site title, tagline, language, timezone and permalinks. Add users, reset passwords and change roles.
* **Troubleshooting:** run a read-only site audit or trace an error. The agent reads the code and shows you where it breaks.

Ask: "Run a full SEO audit of my site and fix any images missing alt text." The agent checks every page, lists what is missing, and writes the alt text across the media library in one pass.

= Manage multiple sites from one chat =

Connect any number of WordPress sites, wherever they are hosted, and work on all of them from one chat. To act on several sites at once, open [AI Studio](https://www.siteground.com/ai-studio/?utm_source=wordpress&utm_medium=plugin-directory&utm_content=description), select which site or all sites and write your prompt. The chat inside each WordPress admin works on that site only. Here are some examples of what you can do across all of your sites at once:

* Update a plugin on every site at once.
* Add a new editor to every client site, or remove someone's access across the portfolio.
* Apply the same timezone, language or permalink structure everywhere.
* Change text or URLs across dozens of pages on several sites at once.

Ask: "Update all plugins on every site." Every connected site updates from one chat, and the agent reports back on each one.

= Power Mode and your controls =

Power Mode is an extra layer of protection, which asks for explicit confirmation whenever the Agent is prompted to change anything major. When a prompt calls for deleting posts, pages, media, plugins, themes, products or orders, creating or changing users, or updating site settings, the agent pauses and shows a warning with an Enable button in the chat. Nothing changes until you click it.

* Only administrators can see and use the agent by default. An administrator can give editors access with a toggle in the plugin settings.
* Hide the chat bubble in the plugin settings. The agent stays available from the AI Agent menu.
* The Activity Log records the page and post changes the agent makes, filtered by category.
* Deactivate and delete the plugin from your Plugins screen at any time.

= SiteGround AI connector =

WordPress 7.0 added a [Connectors screen](https://wordpress.org/download/releases/7-0/), where you link an AI provider, and plugins use that connection for features such as generating text and images or writing alt text. Each provider normally needs its own account, subscription and API keys. The SiteGround AI Agent plugin spares you all of these steps. Once you install and connect the plugin, it sets up SiteGround as your AI provider, with no need for API keys or extra configuration. The AI Agent works with all the latest AI models underneath (Gemini, GPT, Claude, Nano Banana, GPT Image). [Learn more](https://www.siteground.com/tutorials/ai-agent-wordpress/enable-siteground-ai-provider/).

== Installation ==

1. Log in to [SiteGround AI Studio](https://www.siteground.com/ai-studio/?utm_source=wordpress&utm_medium=plugin-directory&utm_content=description). It comes with any active SiteGround service.
2. Install and activate the [AI Agent by SiteGround plugin](https://www.siteground.com/kb/use-wordpress-ai-agent-external-sites/?utm_source=wordpress&utm_medium=plugin-directory&utm_content=description) on your WordPress site.
3. In AI Studio, go to Profile > Connectors > WordPress > Connect, choose Add External Website, enter your domain and copy the connection key. Paste the key into the plugin settings and click Connect.

If your site is hosted with SiteGround, [connect it in one click](https://www.siteground.com/kb/connect-ai-studio-with-wordpress/?utm_source=wordpress&utm_medium=plugin-directory&utm_content=description) with no key. Every site needs an active SSL certificate.

Once connected, chat with the agent from AI Studio or from the chat pop-up inside your WordPress admin.

== Frequently Asked Questions ==

= Why get this plugin? =

* **Work via chat:** Describe what you want in plain language; no expertise needed.
* **WordPress Management quick and easy:** The agent can create new content, edit settings, install or update plugins and more.
* **Edit multiple sites at once:** Connect sites from any host to AI Studio and edit them all with one prompt.
* **Safe by default:** Power Mode warns you about making critical changes and asks for extra permission.
* **20,000 free AI Tokens a month** for every SiteGround customer.

= Do I have to host with SiteGround? =

No. Your site can be hosted anywhere. The agent runs on SiteGround AI Studio, which comes with any active SiteGround service: hosting, a domain or any other product. From one SiteGround account you can connect WordPress sites hosted with any provider. The site needs an active SSL certificate. The Installation tab has the steps.

= How much does it cost? =

The plugin and all of its features are free to use. The agent's work runs on AI Tokens: every SiteGround customer gets 20,000 free AI Tokens each month, and you can add more as a monthly increase or a one-time batch, starting at 100,000 tokens. Tokens measure how much the AI processes, so a short request uses far fewer than a bulk job across a whole catalog.

= Which user roles can use the agent? =

Administrators, by default. An administrator can give editors access with a toggle in the plugin settings. Authors, contributors and other roles do not see the agent and cannot use it.

= The chat bubble is in my way. Can I hide it? =

Yes. Switch it off in the plugin settings.

= Does it work with WordPress Multisite? =

Not yet. The agent works on standalone WordPress installations. You can still connect any number of separate WordPress sites to AI Studio and manage them together.

= I didn't install this plugin. Why is it on my site? =

If your site is hosted with SiteGround, we added this plugin to existing sites when it launched. We should have told you first.

The agent takes no action on its own. It acts only when an administrator gives it an instruction, and deletions, bulk edits and user changes wait behind Power Mode. If you don't want it, deactivate and delete it from your Plugins screen like any other plugin.

== Use of third-party services: what data the plugin sends and when ==

This plugin connects to SiteGround AI Studio, a service operated by SiteGround, at api.studio.siteground.ai. It sends data in three situations:

* **When you use the chat or AI features:** your prompts, the content being edited, and site context (WordPress version, active plugins, theme). Endpoints: /api/v1/* (chat and generation).
* **When you connect, reconnect or disconnect the site, and when keys refresh automatically:** site URL, authentication credentials and plugin version. Endpoints: /[service]/v1/sign/token, /dynamic-keys/v1/key-refresh, /api/v1/wp/wp-disconnect.
* **When you open the plugin dashboard or the plugin checks feature access:** usage statistics requests and user and site identification. Endpoint: /api/v1/usage.
